# Mastered chapters

Mastered chapters land here from `python3 toolkit/media.py audiobook master`, as `<piece>.chNN.mp3`, and are measured by `audiobook check`.
Everything here except this file is ignored by `production/src/.gitignore`: never force a master into Git.
Archive each approved master as source media at once, with `python3 toolkit/media.py footage add`: it is what M4 reads, and its takes need not be kept, so a lost disk would otherwise cost a chapter the author has already approved.
