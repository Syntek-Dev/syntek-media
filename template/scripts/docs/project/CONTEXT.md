# CONTEXT.md — scripts/docs/project/

Guides for planning, writing and boarding a piece, written for this project. The template seeds
only this pair, once; from then on the pair and everything else in the folder are yours, and
`copier update` never changes them. A guide here with the same filename as one in
`scripts/docs/reference/` overrides it entirely; a new filename adds a guide the template does
not have. The one exception is the ladder guide: a guide here of that name may add a check to a
gate, never remove or weaken one. This is where the project's own conventions go — the house
rules for its briefs, its scripts or its storyboards that no other project shares.

## Directory Tree

```text
scripts/docs/project/
├── CONTEXT.md          ← this file
├── CLAUDE.md           ← operating rules
└── <question>.md       ← one guide per question, in the reference guides' shape
```

## What's here

- Guides you have written, each named in kebab-case for the question it answers, with a line
  here for each. **Until you write one, this folder holds only its pair.**

## Cross-references

- `scripts/docs/reference/` — the template's guides, which yours override by name.
- `scripts/docs/CLAUDE.md` — the guide shape, the precedence rule and its one limit.
