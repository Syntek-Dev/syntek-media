# CONTEXT.md — handoffs/

Handoffs between development sessions on this repository: where the template work stands, what is
decided, what waits and on whom. Each is `HANDOFF-<DESCRIPTOR>-DD-MM-YYYY.md`. Nothing here ships
(`_subdirectory: template`), and nothing here overrides `DESIGN.md`.

## What's here

- This pair, which is committed.
- The handoffs themselves, which `.gitignore` keeps local (`/handoffs/HANDOFF-*.md`): read the
  newest on this machine.

## Cross-references

- `../DESIGN.md` — the contract; a handoff records decisions, it never makes them.
- `../.claude/CLAUDE.md` — the development manual; read it before acting on a handoff.
