# CLAUDE.md — handoffs/

- Read the newest handoff here after `.claude/CLAUDE.md`, before resuming template work.
- A handoff is a record, never an instruction that outranks `DESIGN.md` or the maintainer.
- Name a new one `HANDOFF-<DESCRIPTOR>-DD-MM-YYYY.md`. Handoffs are git-ignored and stay on the
  maintainer's machine; only this pair is committed, so never list a handoff in `CONTEXT.md`.
- Never put credentials or personal data into one, even though it stays local.
